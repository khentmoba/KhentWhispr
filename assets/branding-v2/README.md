# SpeakFlow Vector Identity (v2)

## Design Rationale

This identity represents a complete visual departure from the legacy copper acoustic-arcs mark, establishing a distinct, modern identity engineered specifically for the SpeakFlow Windows speech-to-text application.

### Key Visual Concepts

1. **Deep Midnight / Navy Foundation (`#0E1935` → `#081124` → `#03060E`)**
   - Replaces the previous copper background with a rich, dark space navy base tailored for Windows 11 Fluent dark environments.
   - Finished with an ultra-subtle cyan/mint rim sheen and soft central bloom for optical depth.

2. **S-Speech Flow Ribbon Monogram**
   - The central mark fuses an **'S' monogram** with a continuous speech ribbon.
   - **Speech Origin (Upper Loop)**: Curves like a conversation dialogue bubble with a sculpted pointer tail representing spoken voice capture.
   - **Voice Flow (Center Bridge)**: Sweeps downward with continuous mathematical curvature (48px stroke), communicating high-speed real-time streaming.
   - **Text Destination (Active Cursor)**: Accented with an active vertical text-cursor cue (`#00F5A0` → `#00D2F7`), symbolizing instant transcription into typed text.

3. **Mint-to-Aqua Spectrum (`#00F5A0` → `#00E5C9` → `#00D2F7` → `#0284C7`)**
   - High-contrast, luminous electric palette conveying responsiveness, accuracy, and flow.
   - Bold, uncompromised silhouette engineered for legibility across 512px app tiles down to 16px Windows system tray / taskbar icons.

## Asset Deliverables
